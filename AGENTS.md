# Agent Guidelines for Investing Analyser

## Core Principle

**You do only what is asked of you.** Avoid over-engineering or adding unnecessary features.

## Project Structure

### Directory Organization

```
src/
  ingestion/        # Data processing functions
  plots/            # Visualization functions

notebooks/          # Jupyter notebooks for analysis

docs/              # Documentation

sanitized_data/    # Output folder (auto-generated by ingestion)

data/              # Raw input files (don't modify)
```

### Code Organization

#### Ingestion Functions (`src/ingestion/`)

Each index has exactly one file: `ingest_<indexname>.py`

**Requirements:**
- Function signature: `def ingest_<indexname>():`
- Returns: DataFrame with columns `date` (datetime) and `price` (float)
- Side effect: Creates CSV in `sanitized_data/<indexname>.csv`
- Pattern: Read → Sanitize → Sort → Save → Return
- Error handling: Suppress openpyxl warnings with `warnings.catch_warnings()`

#### Plot Functions (`src/plots/`)

Currently two plot types:
- `absolute_price.py` - `plot_absolute_price(df, title)`
- `rentability.py` - `plot_rentability(df, title)`

**Requirements:**
- Accept DataFrame with `date` and `price` columns
- Create matplotlib figure
- Format with proper labels, dates, grid
- Call `plt.show()` at end

**New plot types:** Create new file `<plottype>.py` with `def plot_<plottype>(df, title):`

## Adding a New Index

1. Create `src/ingestion/ingest_<newindex>.py`
2. Implement `ingest_<newindex>()` function
3. Test: Run function and verify CSV in `sanitized_data/`
4. Add cells to `notebooks/absolute_price.ipynb` and `notebooks/rentability.ipynb`
5. Update documentation if significant changes

## Notebook Updates

When modifying notebooks:
- Keep first cell with: `sys.path.insert(0, '..')` and `os.chdir('..')`
- Reference sanitized CSV files: `sanitized_data/<name>.csv`
- Use relative paths from project root (after chdir)
- Don't mix data ingestion and visualization in same notebook

## Documentation

- User-facing docs: `docs/` folder (markdown)
- Code comments: Only add if logic is non-obvious
- Function docstrings: Not required unless complex
- Keep inline comments minimal per project preference

## File Modifications

- **Safe to modify:** `src/`, `notebooks/` (except main), `docs/`
- **Auto-generated:** `sanitized_data/` contents

## Workflow Patterns

### For new ingestion:
```
Create src/ingestion/ingest_<name>.py
  → Test function works
  → Add to ingestion.ipynb imports
  → Add cells to absolute_price.ipynb
  → Add cells to rentability.ipynb
```

### For new visualization:
```
Create src/plots/plot_<name>.py with plot_<name>() function
  → Create new notebook or add cells to existing
  → Verify plots render correctly
```

## Important Notes

- **Keep functions pure** - no side effects except file I/O
- **Use pathlib** (Path) for all file operations
- **Absolute vs relative paths:** Always use relative from project root
- **Timestamps:** All dates should be datetime64[ns] after ingestion
